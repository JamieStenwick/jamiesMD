Release Notes#

This section documents major changes to the MathDx package and its components. Detailed changes for individual libraries are in the corresponding library’s release notes.

26.06.1#

This patch release includes bug fixes for cuBLASDx and cuFFTDx, and minor changes to the documentation of Dx libraries.

Please refer to the release notes of the corresponding libraries for more details.

Components#

  • cuFFTDx 1.7.3: release notes

  • cuBLASDx 0.7.1: release notes

  • cuSolverDx 0.5.0: release notes

  • cuRANDDx 0.2.4: release notes

  • nvCOMPDx 0.1.4: release notes

26.06.0#

Major changes in this release:

  • Deprecated static LTO libraries in cuSolverDx and nvCOMPDx.

  • cuBLASDx added flexible-precision floating-point emulation GEMM along with improvements to pipelined GEMM.

  • cuSolverDx added experimental cluster execution for POTRF.

  • nvCOMPDx added support for MSVC when using fatbin library.

  • MathDx 26.06.0 package ships with CUTLASS 4.5.2, and this is the recommended version to use.

Please refer to the release notes of the corresponding libraries for more details.

Components#

  • cuFFTDx 1.7.1: release notes

  • cuBLASDx 0.7.0: release notes

  • cuSolverDx 0.5.0: release notes

  • cuRANDDx 0.2.4: release notes

  • nvCOMPDx 0.1.4: release notes

26.03.0#

Major changes in this release:

  • Dropped support for CUDA Toolkit 12.X.

  • Dropped support for Volta architecture (SM70/SM72).

  • cuBLASDx 0.6.0 adds TRSM functionality and is now an LTO library.

Please refer to the release notes of the corresponding libraries for more details.

Components#

  • cuFFTDx 1.7.0: release notes

  • cuBLASDx 0.6.0: release notes

  • cuSolverDx 0.4.0: release notes

  • cuRANDDx 0.2.3: release notes

  • nvCOMPDx 0.1.3: release notes

25.12.1#

25.12.1 patch release includes minor changes to the documentation and samples of cuBLASDx and cuFFTDx.

Components#
